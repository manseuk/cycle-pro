## Question

What is a user's training goal in the MVP? Define the supported goal kinds, required inputs and measurable outcomes, how a goal is created or edited, and how event-based goals differ from general-fitness goals. The current direction is editable event/date plus measurable target, with general fitness also supported.

## Answer

The MVP supports two goal types: event goals and general-fitness goals. An event goal requires an event and date; completion is the default outcome, with target finish time optional. A general-fitness goal is measured by a weekly ride-frequency or riding-time target; the user may add a power target such as FTP. Users can start from editable templates or enter a custom goal, but have one primary active goal at a time. See [GLOSSARY.md](../../../GLOSSARY.md) for the agreed domain terms.
