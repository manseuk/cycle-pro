## Question

What should the new Cycle Pro look like? Produce 2–3 rough, mobile-first visual directions, each shown in light and dark, for the user to react to and choose one. No existing website as reference; modern look. Link the prototype as an asset.

## Answer

Variant **B, "Performance board"** chosen. Bold uppercase headings, big tabular numbers, ruled rows instead of cards, hard-edged calendar cells. Light theme is black on off-white with lime highlights; dark theme is near-black with a lime accent. Navigation: full-screen numbered menu opened from a MENU button on phones, horizontal top tabs on desktop. Theme toggle sits in the top bar. Light is the default (the user prefers it); dark must be fully supported.

Prototype (throwaway, not on main): branch `prototype/visual-direction`, files `apps/web/prototype.html` and `apps/web/src/prototype/`. Run with `pnpm proto:ui` on that branch. Rejected: A "App shell" (bottom tab bar, cards) and C "Journal" (serif, timeline, title-as-menu).
